# Ex. 1 – Working with Widgets and Layouts
24CS2016 – Building Applications using Flutter

Fruit list app using ListView, Card, Container, Row, Column and a reusable `FruitItem` widget.

## Run
1. Replace the placeholder images in `assets/images/` with your own
   (apple.jpeg, banana.jpeg, mango.jpeg, orange.jpeg).
2. `flutter pub get`
3. `flutter run -d chrome`
