# Ex. 4 – Form Validation using Stateful Widgets
24CS2016 – Building Applications using Flutter

Car Mileage Calculator using Form, TextFormField, TextEditingController and setState().
Mileage < 10 km/l = Poor, 10-15 = Average, > 15 = Excellent.

## Run
1. `flutter create .`   (first time only, adds android/web/etc. folders)
2. `flutter pub get`
3. `flutter run -d chrome`
