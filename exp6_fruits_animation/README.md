# Experiment 6 - Animated Fruits List (Flutter)

Features: slide-up + fade-in list animation, replay button, animated favorite icon.

## Run (one-time setup, then run)
1. Extract the zip and open a terminal inside the `exp6_fruits_animation` folder.
2. Generate platform folders (android/ios/web etc.) - only needed once:

       flutter create .

3. Get packages and run:

       flutter pub get
       flutter run

(In VS Code / Android Studio: open the folder, run the `flutter create .` step in the terminal, then press F5 / Run.)

## Your own images
Replace assets/apple.png, assets/orange.png, assets/mango.png with real photos (keep the same file names).
