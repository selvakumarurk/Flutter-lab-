# Ex. 3 – Add Interactivity to App: Input and Forms
24CS2016 – Building Applications using Flutter

Product search app: a TextField filters a predefined product list (ListView.builder + Card + ListTile),
with a clear button and a "No products found" state.

## Run
1. `flutter create .`   (first time only, adds android/web/etc. folders)
2. `flutter pub get`
3. `flutter run -d chrome`
