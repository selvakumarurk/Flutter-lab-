# Ex. 5 – Implementation of Navigation and Routing
24CS2016 – Building Applications using Flutter

Two screens (Student Details -> Student Result) using named routes, Navigator.pushNamed() with
arguments, ModalRoute.of(context)!.settings.arguments, and Navigator.pop().

Files in lib/: main.dart, user_data_model.dart, home_screen.dart, second_screen.dart

## Run
1. `flutter create .`   (first time only, adds android/web/etc. folders)
2. `flutter pub get`
3. `flutter run -d chrome`
